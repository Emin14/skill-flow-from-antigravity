# Проверка процесса — 2026-11-03

В этом изменении canonical dataset не редактировался.

## Исправлено

- Выбор записи по слову больше не берёт молча последний омограф. Явная выборка связывается с `dataset_index`; индекс проверяется при создании и применении manifest. Старый отчёт без индекса для неоднозначного слова останавливается с объяснением. В одной партии по-прежнему нужны 20 различных заголовочных слов; омографы следует распределять в разные партии.
- Dispatcher сохраняет `selected_indices.json` и запрещает переиспользовать папку для другой выборки.
- Убрана автоматическая семантическая поблажка для green. Все пять ролей получают полные записи и полные предыдущие отчёты. Это увеличивает входной контекст, зато не скрывает примеры и before/after от проверяющего.
- После каждой роли выполняется общий gate доступных этапов. При подготовке отдельной роли проверяются предшественники. Кэшированные ответы проходят ту же проверку.
- `validate_stage.py` использует общий gate вместо несовместимого отдельного набора правил.
- Проверяются наличие поиска по всем PDF/DOCX из инвентаризации, дубли источников, запрос и логический found. Цитаты сверяются с текстом указанной страницы PDF или абзаца DOCX. Допускается только нормализация пробелов и Unicode NFC. Отсутствие извлекаемого текста требует исправления источника/ссылки; доказательство не принимается автоматически.
- При передаче canonical entries gate проверяет точный before, покрытие всех значений роли 08 и логические флаги primary с хотя бы одним основным значением. Нумерация значений в запросе явно указана как начинающаяся с 1.
- Пустой корень отчётов не считается успешным аудитом. Boolean больше не принимается как confidence.
- CLI-адаптер передаёт запрос через stdin, соблюдает выбранный sandbox и не копирует весь словарь в рабочую папку агента. Избыточный доступ к каталогу Codex убран.

## Границы результата

Это проверка и усиление программных механизмов, а не повторный лингвистический аудит 4980 слов. Реальный прогон CLI-агентов на простой модели в этой работе не выполнялся. Нельзя обещать одинаковое качество любых моделей без контрольного сравнения.

Новый gate строже старого: ранее принятые отчёты могут потребовать исправления цитат, заполнения поиска по пропущенным источникам или явных индексов. Уже применённый отчёт содержит исторический before; его нельзя проверять как новую заявку к изменившемуся словарю.

Существующие внешние оркестраторы и другие скрипты изменения словаря требуют отдельного аудита. Полная проверка всех путей записи, конкурентных запусков, аварийного восстановления и всех требований к семантическим обоснованиям ещё не доказана. Здесь не заявляется, что словарь или весь процесс стал идеальным.

Поправка после реального прогона: требование ровно одного primary было ошибкой валидатора. Словарь допускает несколько основных значений; их выбор остаётся семантической задачей роли 08. Проверка полного покрытия значений сохранена.
