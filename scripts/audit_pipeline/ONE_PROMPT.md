# Единый промпт строгого аудита

Обработай диапазон слов из `src/data/oxford_5000.json` партиями по 20.
Для каждой партии выполни пять независимых этапов 06→07→08→09→10. Каждый этап обязан сохранить JSON-результат для каждого слова. Не используй общие причины и не пропускай доказательства.

06: найди совпадения в PDF/DOCX/распарсенном PDF; укажи файл, страницу и короткую цитату. Если источники не подтверждают улучшение, объясни это конкретно.
07: сравни текущую запись с evidence и предложи изменение только при доказанном улучшении.
08: отдельно проверь порядок и `primary`, не удаляй значения.
09: проверь учебную понятность, части речи и примеры.
10: отклони результат без evidence, before/after, причины или confidence.

Спорные случаи получают `decision: review_required` и `review_reason`; автоматически их не менять.
После каждой партии запусти `python3 final_qa_validation.py`, сохрани отчёт и progress. Любая ошибка останавливает конвейер.
