# Проверка 20 слов и улучшение процесса

Изменены **18 из 20 слов**. Добавлены **44 примеров**, исправлены **39 полей** и добавлены **0 фраз**. Пустых значений осталось **34 из 78**. Проверка отчётов 06–10 и итоговая QA прошли с нулём ошибок. Старые примеры, ID и порядок значений сохранены.

Два отдельных омографа live из позиций 239–240 записаны в deferred_homographs.json для следующих партий. В текущем списке одна запись live и 19 других заголовков. Правки порядка и primary вынесены в рекомендации по словам. Три предложения заменить существующие примеры (today, point, read) отложены и указаны в approved_changes.deferred.json.

## Что изменилось в процессе

- Короткие ID отработали в живой партии. Все 160 ссылок роли 06 прошли развёртывание в имена файлов и проверку цитат с первой попытки. Ответ до развёртывания был примерно на 19 КБ меньше.
- Четыре номера значений full восстановлены по словам и примерам, которые агент уже указал в обоснованиях. После повторной проверки роль 09 получила исправленный отчёт. Роль 08 не запускалась повторно.
- Проверки конкурирующих кандидатов, причин отсутствия примера и привязки sense_after теперь выполняются до роли 10. На исходном ответе этой партии новая проверка точно находит point/14. Финальные условия приёмки те же. 68 тестов прошли.
- Для point/14 автор уточнил анатомический контекст и привязал новый пример к точному значению. Независимый агент проверил только обновлённый кандидат. Остальные 59 решений по примерам сохранены.
