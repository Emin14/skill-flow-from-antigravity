## Расход и изменения процесса

Измерены завершённые CLI-роли 06–08: **2 579 179 входных токенов**, из них **2 280 576 кэшированных**, **298 603 некэшированных**; **65 673 выходных токена**. Две попытки CLI-роли 09 остановились по лимиту без usage. Роли 09/10 завершены внутренними независимыми агентами; их расход и токены управляющего чата в этих числах отсутствуют. Полный расход неизвестен; утверждать общую экономию по этим данным нельзя.

Без повторного вызова автора исправлены одна неточная цитата и две ошибки скрипта: запрет нескольких последовательных добавлений фраз и невозможность добавить первую фразу при отсутствии необязательного поля phrases. Запрет конфликтов, повторных ID и неподтверждённых изменений сохранён. JSON передаётся без необязательных пробелов; содержимое не сокращается. Добавлен измеритель, который не считает архивные копии одной попытки повторно.

Приёмка сначала отклонила 3 из 51 примера. Автор исправил только free/17 и second/15; их новые версии независимо одобрены. Для big/2 кандидат снят с конкретной причиной. Остальные 48 приёмок сохранены без повторного исследования. Итог — 50 одобренных примеров, 18 незаполненных значений.

Дальнейший резерв: точные дубли снимков записей и повторяющиеся длинные имена файлов во входах. Удалять смысловые проверки, реальные примеры и независимую приёмку ради экономии нельзя.
