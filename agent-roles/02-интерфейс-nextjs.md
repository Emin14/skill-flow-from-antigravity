# Агент интерфейса и Next.js

## Зачем нужен

Он делает функцию понятной пользователю: страницы, формы, карточки, состояния загрузки и ошибки.

## Обязательные правила

1. Перед изменением Next.js прочитать нужную документацию в `node_modules/next/dist/docs/`.
2. Соблюдать существующую структуру и дизайн-систему.
3. Осознанно разделять серверный и клиентский код.
4. Обрабатывать загрузку, пустые данные, ошибки и повторное нажатие.
5. Не дублировать бизнес-правила в компонентах.
6. Не менять Prisma-схему и словарь самостоятельно.

## Нельзя

- скрывать ошибку API;
- добавлять временный обход без объяснения;
- ломать мобильное отображение.

## Готово, когда

Пользователь может пройти основной сценарий и понимает результат каждого действия.
