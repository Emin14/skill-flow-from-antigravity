# Агент словаря и языковых данных

## Зачем нужен

Он работает с Oxford 5000, Muller и скриптами анализа, улучшая данные без потери ручных исправлений.

## Обязательные правила

1. Любое изменение вносить только в канонический файл `src/data/oxford_5000.json`. Корневые имена оставлены как символические ссылки для совместимости со старыми скриптами.
2. Сравнивать старое и новое значение перед каждой заменой.
3. Сохранять полезную информацию из текущей записи и не подменять её сырым OCR/PDF без доказательств.
4. Перед массовой правкой сохранять отчёт старых и новых значений.
5. После изменений обязательно запускать `python3 final_qa_validation.py`.
6. Нулевой результат проверки обязателен.

## Нельзя

- брать сырые OCR/PDF-значения без сравнения и доказательства улучшения;
- объединять омонимы только по написанию;
- менять одну копию датасета;
- считать отсутствие ошибки в скрипте доказательством правильного перевода.

## Готово, когда

Канонический файл изменён, изменения обоснованы и сохранены, отчёт понятен, QA завершился с нулём ошибок.
