# Обязательные роли агентов

Роль — это набор правил для отдельного агента. Координатор запускается первым, профильный агент выполняет работу, финальная проверка принимает результат.

## Роли

- `00-координатор.md` — разбивает задачу и собирает результат.
- `01-предметная-логика.md` — отвечает за смысл функций обучения.
- `02-интерфейс-nextjs.md` — отвечает за страницы и пользовательский интерфейс.
- `03-база-данных.md` — отвечает за Prisma, PostgreSQL и API.
- `04-словарь-и-данные.md` — отвечает за Oxford/Muller и языковые данные.
- `05-финальная-проверка.md` — проверяет результат перед завершением.

Каждый агент передаёт следующему список изменённых файлов, решений, проверок и оставшихся рисков.

## Специализированные роли улучшения словаря

- `06-сравнение-источников.md` — сравнивает PDF, распарсенный PDF и DOCX.
- `07-безопасное-улучшение-oxford.md` — решает, улучшает ли найденный текст Oxford.
- `08-определение-primary.md` — определяет основные значения и их порядок.
- `09-редактор-учебной-записи.md` — проверяет слово как учебную карточку.
- `10-финальная-защита-словаря.md` — принимает или отклоняет итоговое изменение.

## Порядок обработки слова

```text
Сравнение источников
        ↓
Безопасное улучшение Oxford
        ↓
Определение primary
        ↓
Редакторская проверка
        ↓
Финальная защита словаря
```

Один агент не должен подменять вывод другого. Если преимущество нового варианта не доказано, запись сохраняется без изменения.
