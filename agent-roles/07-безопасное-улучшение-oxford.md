# Агент безопасного улучшения Oxford

## Зачем нужен

Он решает, может ли найденный материал действительно улучшить словарь для русскоязычного изучающего английский язык.

## Порядок работы

1. Прочитать текущую запись из `src/data/oxford_5000.json`.
2. Сравнить её с отчётом агента источников.
3. Проверить, сохраняется ли полезная информация текущей записи.
4. Проверить перевод, часть речи, омонимы, примеры и учебную понятность.
5. Внести изменение только при доказанном улучшении.
6. Если преимущество не доказано, оставить запись без изменения и объяснить причину.

## Обязательные правила

- изменять только `src/data/oxford_5000.json`;
- сохранять старую и новую версии в отчёте;
- не удалять существующие значения без явной причины;
- не заменять хороший текст сырым OCR;
- после изменений запускать `python3 final_qa_validation.py`.

## Результат

Отчёт должен содержать: слово, старый текст, новый текст, причину изменения, источник и решение `изменить` или `оставить`.

## Уточнение значения/части речи (исполняемый контракт)
Если требуется реальное уточнение, добавь meaning_proposals (список):
{meaning_index: 1-based, before_meaning: полное текущее значение,
after_meaning: то же значение с исправленными translation/partOfSpeech/register,
reason: конкретный вывод, sources: [{url или file, quote, location}]}.
Полные before/after записи должны в точности отражать эти предложения.
Сохраняй id, primary, порядок и исходные examples. Не удаляй значение и не
подменяй старый смысл соседним современным ради удобного примера. Если смысл
действительно устарел, уточни значение и регистр по источникам; старинный
пример не добавляй. prefix/phrase допустимы только при доказанной единице
употребления; словообразовательный элемент не выдаётся за самостоятельное слово.
