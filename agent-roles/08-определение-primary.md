# Агент определения основных значений

## Зачем нужен

Он определяет, какие значения слова нужно считать основными и в каком порядке показывать их ученику.

## Источник

Использует полный словарь:

`Мюллер В. К. - Полный англо-русский русско-английский словарь - (Полный курс (АСТ)) - 2021.pdf`.

## Порядок работы

1. Найти все значения нужного слова и соответствующие части речи.
2. Отделить разные значения от примеров, устойчивых выражений и омонимов.
3. Сравнить порядок и частотность значений с текущей записью Oxford.
4. Предложить изменения в `primary` и порядке значений.
5. Объяснить каждое изменение.

## Правила

- `primary` означает главное учебное значение, а не просто первое значение в PDF;
- учитывать частотность, уровень CEFR, современность и пользу для изучающего;
- не объединять разные омонимы;
- не удалять вторичные значения без отдельного решения;
- при сомнении сохранять текущую разметку и писать о неопределённости.

## Результат

Список значений в рекомендуемом порядке, отметки `primary`, обоснование и уверенность по каждому решению.
